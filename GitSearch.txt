GITSEARCH
Universal Git Repository Search, Discovery, Analysis and Code Archaeology Platform

Version: 1.0
Status: Functional Specification

================================================================================
1. PURPOSE
================================================================================

GitSearch is a high-performance repository intelligence platform designed to
search, analyze, and trace any information that exists or has existed within a
Git repository.

The platform extends beyond traditional code search by allowing developers to
search repository content, commits, branches, tags, history, metadata, deleted
code, renamed files, symbols, dependencies, and code evolution.

The objective is to make every piece of information inside a Git repository
instantly discoverable regardless of whether that information exists in the
current repository state or only in historical commits.

4. SEARCH MODES
================================================================================

MODE: CURRENT FILES

Description:
Search current repository state only.

Scope:
Current files in current checkout.

Example:

gitsearch "CustomerId"

================================================================================

MODE: CURRENT BRANCH

Description:
Search current branch current state.

Example:

gitsearch "CustomerId" --current-branch

================================================================================

MODE: SELECTED BRANCHES

Description:
Search specific branches.

Example:

gitsearch "CustomerId" --branch develop

Example:

gitsearch "CustomerId" --branch develop,release,hotfix

================================================================================

MODE: ALL BRANCHES

Description:
Search all branch heads.

Example:

gitsearch "CustomerId" --all-branches

================================================================================

MODE: CURRENT BRANCH HISTORY

Description:
Search all commits in current branch.

Example:

gitsearch "CustomerId" --branch-history

================================================================================

MODE: SELECTED BRANCH HISTORY

Description:
Search commit history for one or more branches.

Example:

gitsearch "CustomerId" --branch-history develop

================================================================================

MODE: ALL HISTORY

Description:
Search every commit reachable from all branches.

Example:

gitsearch "CustomerId" --history

================================================================================

MODE: SPECIFIC COMMIT

Description:
Search a single commit.

Example:

gitsearch "CustomerId" --commit a1b2c3d

================================================================================

MODE: MULTIPLE COMMITS

Description:
Search a predefined list of commits.

Example:

gitsearch "CustomerId" --commits a1b2c3d,b2c3d4e,c3d4e5f

================================================================================

MODE: COMMIT RANGE

Description:
Search between commits.

Example:

gitsearch "CustomerId" --range a1b2c3d..z9y8x7w

================================================================================

MODE: SPECIFIC TAG

Description:
Search a specific tag/release.

Example:

gitsearch "CustomerId" --tag v5.1

================================================================================

MODE: TAG RANGE

Description:
Search between releases.

Example:

gitsearch "CustomerId" --between-tags v5.0 v6.0

================================================================================

MODE: REPOSITORY LIFETIME

Description:
Maximum search scope.

Includes:

All Branches
All Commits
All Tags
Deleted Files
Renamed Files
Historical Content

Example:

gitsearch "CustomerId" --repository-lifetime
